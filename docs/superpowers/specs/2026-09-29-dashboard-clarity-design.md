# 资产总览清晰化与图表设计

## 目标

让资产总览优先展示用户已经录入的真实数据，减少不必要的“陈旧确认”阻断，并用轻量图表直观呈现资产变化和现金分配。

## 行为

- 只要现金桶、持仓和正式净值具备可计算数据，资产总览直接显示总资产。
- 缺少必要数据时显示“待补充”，但不把缺失值当作零。
- 总览和日常建议不再因为时间阈值要求用户确认“数据陈旧”。
- 现金桶和分析标签使用中文：生活备用金、可投资现金、合计现金。
- 保留数据日期和来源作为轻量说明，不显示冗余规则提示。

## 视觉

- 保留现有服务端 SVG 趋势图，增加现金分配与核心/卫星占比图。
- 图表不依赖外部 CDN 或第三方库，移动端保持可读。
- 无数据时显示简洁空状态；有数据时显示数值和比例。

## 边界

- 不修改数据库结构和现有理财数据。
- 不把盘中估算计入正式总资产。
- 不自动交易、不预测收益。

## 验证

- 总览在存在现金和正式净值但时间超过阈值时仍展示总资产。
- 缺少现金或正式净值时仍展示“待补充”。
- 现金桶标签不包含英文内部枚举值。
- 图表数据在有值、部分值和空值时均能渲染。
